# Definition of Done

Історія вважається виконаною, якщо:

- [ ] Код у PR, злитий у `main` (squash merge) після рецензії або самоперевірки.
- [ ] CI зелений (`./mvnw -B verify`).
- [ ] Для формул грошей (округлення, комісії, збори) є параметризовані тести з конкретними числами.
- [ ] Для змін схеми БД додано нову міграцію Flyway (стара не редагується).
- [ ] `ArchitectureTest` проходить: межі модулів не порушені.
- [ ] Документація оновлена (README, docs/*, ADR, якщо рішення нове).
- [ ] Усі критерії приймання (Given/When/Then) перевірені і відмічені в issue.
- [ ] У описі PR є `Closes #N`.
- [ ] Немає нових попереджень, TODO без issue, закоментованого коду.
- [ ] Український текст не містить довгого тире і забороненого слова (дивись CONTRIBUTING.md).
